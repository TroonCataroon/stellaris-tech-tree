# Stellaris Tech Tree - GitHub Pages Setup

## 🌐 How to Deploy to GitHub Pages (github.io)

Your repository is already set up at: `https://github.com/TroonCataroon/stellaris-tech-tree`

### Step-by-Step GitHub Pages Setup:

#### 1. Go to Your Repository Settings
- Navigate to: `https://github.com/TroonCataroon/stellaris-tech-tree`
- Click the **"Settings"** tab (at the top of the repository)

#### 2. Enable GitHub Pages
- Scroll down to **"Pages"** in the left sidebar
- Under **"Source"**, select **"Deploy from a branch"**
- Choose **"events-tab"** (or "master" if you want to use the main branch)
- Select **"/ (root)"** as the folder
- Click **"Save"**

#### 3. Your Site Will Be Available At:
```
https://trooncataroon.github.io/stellaris-tech-tree/
```

#### 4. Optional: Custom Domain
If you have a custom domain, you can set it up in the same Pages settings.
